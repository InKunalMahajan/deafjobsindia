# DeafJobsIndia Visual Design System

## Main palette
- Purple — primary brand/accent
- White — main page background
- Light Gray — cards, borders, secondary surfaces
- Black — headings, body text, strong contrast

Core values:
- Purple 700: #5B21B6
- Purple 600: #6D28D9
- Purple 500: #7C3AED
- Soft Purple 100: #EEE7FF
- White: #FFFFFF
- Light Gray: #F5F5F6
- Border Gray: #E5E7EB
- Black/Ink: #111111
- Muted Gray: #6B7280

## Category colors
Keep category colors only as small accents:
Jobs blue, Education purple, Government Schemes orange/brown,
Training teal, Job Fairs magenta, Community plum,
Technology cyan/blue, Career green.

Use these only in category badges, small left borders, and compact section markers.

## Direction
Clean, professional, modern, editorial, accessible, and spacious.
