# DeafJobsIndia Newsroom Checklist

Use this before every real story is published.

## Accuracy
- [ ] Headline matches the source.
- [ ] Names and organisations are correct.
- [ ] Dates and deadlines are correct.
- [ ] Eligibility is not guessed.
- [ ] Salary, fees, benefits or vacancies are verified.
- [ ] Location and mode are verified.
- [ ] No old notice is presented as new.

## Source
- [ ] Source name is included.
- [ ] Official/source URL is included when available.
- [ ] Source type is correct.
- [ ] `verificationStatus: verified`
- [ ] `verifiedAt` is completed.
- [ ] Source note explains what was checked.

## Deaf-community relevance
- [ ] Accessibility claims are verified.
- [ ] Interpreter/sign-language availability is not assumed.
- [ ] Deaf-friendly claims are supported by a source.
- [ ] Contact instructions do not rely only on a phone call when a text/email/web option is available in the source.

## Writing
- [ ] Important facts come first.
- [ ] English is simple and clear.
- [ ] Full source text is not copied.
- [ ] Image has useful alt text.
- [ ] Action link goes to the official destination.

## Final
- [ ] No `REPLACE:` text remains.
- [ ] No `example.com` placeholder remains.
- [ ] `npm run content:audit` passes.
- [ ] Story preview looks correct on mobile.
