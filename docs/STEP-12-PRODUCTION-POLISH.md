## Before launch

2. Add real social profile URLs in `src/data/site.ts`.
3. Add a contact email.
4. Update the production domain in `astro.config.mjs` if needed.
5. Run `npm run content:audit`.
6. Run `npm run build`.
7. Upload the generated `dist/` contents to Hostinger `public_html/`.
