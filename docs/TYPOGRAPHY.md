# DeafJobsIndia Typography

## Font family

The theme uses this font stack:

```css
font-family:
  "Google Sans",
  "Google Sans Text",
  "Segoe UI",
  Arial,
  Helvetica,
  sans-serif;
```

No Google Sans font files are bundled in the project.

If Google Sans is available on the user's device, the browser uses it.
Otherwise the site falls back to the system UI font.

## Base font size

- Body: 16px
- Line height: 1.6
- Body weight: 400
- Article body: 16px

Headings are intentionally moderate rather than oversized for a normal news-reading experience.
